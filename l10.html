Datalog: family tree and access control实验 10：Datalog（家族树与访问控制）

Goal实验目标
Encode the Addams family in AbcDatalog and derive relatives with rules, then build an access-control system: DAC, delegation, roles and mandatory access control. Rules below were checked with a small evaluator.在 AbcDatalog 中录入亚当斯家族，用规则推导亲属关系，然后构建访问控制系统：DAC、委托、角色和强制访问控制。下面的规则都用一个小型求值器验证过。

🎯 What the exam asks考点

  • With sibling(A,B) :- parent(A,C), parent(B,C). a person is also their own sibling, and siblings are found through any shared parent (example paper Q31).
  • Recursion is what SQL struggles with (example paper Q30).
  • 对 sibling(A,B) :- parent(A,C), parent(B,C).，一个人也是自己的兄弟姐妹，并且通过任一共同父母都能找到兄弟姐妹（样卷第 31 题）。
  • 递归正是 SQL 不擅长的（样卷第 30 题）。

⚠️ Common mistakes易错点

  • Mixing up argument order: the lab uses parent(Child, Parent).
  • Variables must start with an upper-case letter; sharron is a constant, Sharron a variable.
  • Every variable in the head must appear in the body.
  • 参数顺序搞反：实验约定 parent(孩子, 父母)。
  • 变量必须大写开头；sharron 是常量，Sharron 是变量。
  • 头部出现的每个变量都必须出现在规则体里。

#The Addams family亚当斯家族

Tasks: check parent(X, sharron); define sibling (and fix sibling(wednesday, wednesday)); cousin; aunt/uncle; whose uncle is Fester; Pugsley's and Debbie's aunts and uncles.

任务：检查 parent(X, sharron)；定义兄弟姐妹（并修正 sibling(wednesday, wednesday)）；堂表亲；叔舅姑姨；Fester 是谁的叔叔；Pugsley 和 Debbie 的叔舅姑姨。

parent(gomez, father).   parent(gomez, eudora).

parent(morticia, fatherFrump). parent(morticia, hester).
parent(ophella, fatherFrump).  parent(ophella, hester).
parent(eudora, mooma).  parent(eudora, slurp).

Show reference solution展开参考答案try it yourself first先自己做
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
sibling(X, Y)     :- parent(X, P), parent(Y, P), X != Y.
cousin(X, Y)      :- parent(X, P), parent(Y, Q), sibling(P, Q).
auntOrUncle(X, A) :- parent(X, P), sibling(P, A).

parent(X, sharron)?          -> debbie
sibling(gomez, X)?           -> fester
cousin(gomez, morticia)?     -> true  (Eudora and Father Frump are siblings)
auntOrUncle(X, fester)?      -> pugsley, wednesday, pubert
auntOrUncle(pugsley, A)?     -> fester, ophella
auntOrUncle(debbie, A)?      -> none

Defining cousin as "children of siblings" avoids needing negation ("shares a grandparent but is not a sibling" would need not). The ?-at-the-end query form is how AbcDatalog's GUI is used in the lab; the lecture writes queries as ?- p(X).

把堂表亲定义为“兄弟姐妹的孩子”就不需要否定（“有共同祖父母但不是兄弟姐妹”需要 not）。实验里 AbcDatalog 图形界面的查询写法是末尾加 ?；讲座写成 ?- p(X).。

#Access control: DAC, delegation, roles访问控制：DAC、委托、角色

Show reference solution展开参考答案try it yourself first先自己做
% discretionary
canRead(P, F) :- owner(F, P).
canRead(P, F) :- principal(P), othersCanRead(F).
% delegation: A speaks for C if A delegates (possibly via others) to C
speaksFor(A, A) :- principal(A).
speaksFor(A, C) :- delegatesTo(A, B), speaksFor(B, C).
canRead(P, F) :- owner(F, O), speaksFor(O, D), saysCanRead(D, P, F), principal(P).
% roles: a grant may name a role instead of a principal
canRead(P, F) :- owner(F, O), speaksFor(O, D), saysCanRead(D, R, F), holds(P, R).

Tested cases: a non-owner's saysCanRead has no effect; bob → carol → dave delegation lets dave grant bob's file; a grant to role auditor reaches whoever holds it. Without principal(P) in the third rule, the role name itself would appear as a reader.

测试过的情况：非属主的 saysCanRead 无效；bob → carol → dave 的委托链让 dave 能授权读 bob 的文件；授权给角色 auditor 会传到持有该角色的人。第三条规则若不加 principal(P)，角色名本身也会被当成读者。

#Mandatory access control强制访问控制

Show reference solution展开参考答案try it yourself first先自己做
level(unclassified). level(secret). level(topsecret).
below(unclassified, secret). below(secret, topsecret). below(unclassified, topsecret).
atMost(X, X) :- level(X).
atMost(X, Y) :- below(X, Y).
fileLevel(F, unclassified) :- unclassified(F).
fileLevel(F, secret)       :- secret(F).
fileLevel(F, topsecret)    :- topsecret(F).
% Bell-LaPadula (confidentiality): read down, write up
blpRead(P, F)   :- clearance(P, C), fileLevel(F, L), atMost(L, C).
blpWrite(P, F)  :- clearance(P, C), fileLevel(F, L), atMost(C, L).
% Biba as stated in the lab (integrity): write strictly down, read strictly up
bibaWrite(P, F) :- clearance(P, C), fileLevel(F, L), below(L, C).
bibaRead(P, F)  :- clearance(P, C), fileLevel(F, L), below(C, L).

Datalog has no arithmetic comparison here, so the ordering is written as facts. For a secret principal: BLP read = unclassified + secret, write = secret + topsecret; Biba (lab wording) read = topsecret, write = unclassified.

这里的 Datalog 没有算术比较，所以等级顺序用事实写出来。对 secret 级主体：BLP 可读 unclassified + secret，可写 secret + topsecret；Biba（按实验说法）可读 topsecret，可写 unclassified。
