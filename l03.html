Lab 03 · Regular expressions正则表达式

Regular expressions: grep and sed实验 3：正则表达式（grep 与 sed）

Goal实验目标
Search the dictionary with grep, rewrite text with sed, and learn the less obvious grep options.用 grep 搜索单词表，用 sed 改写文本，并掌握 grep 不那么常用的选项。
Lecture notes对应讲义W3 Regular expressions正则表达式
Lab sheets实验原文README.md solutions.org

🎯 What the exam asks考点

  • [ft] means "f or t", not "ft" (example paper Q7).
  • colou\?r matches colour and color; colo[ou]r does not match color (example paper Q8).
  • Regular expressions cannot count/match "n a's then n b's" — no memory (example paper Q9).
  • Count letters with grep -o 'a' file | wc -l, not grep -c (example paper Q10).
  • [ft] 表示 “f 或 t”，不是 “ft”（样卷第 7 题）。
  • colou\?r 匹配 colour 和 color；colo[ou]r 不匹配 color（样卷第 8 题）。
  • 正则无法匹配 “n 个 a 接 n 个 b”——它没有记忆（样卷第 9 题）。
  • 统计字母出现次数用 grep -o 'a' file | wc -l，不能用 grep -c（样卷第 10 题）。

⚠️ Common mistakes易错点

  • Forgetting quotes: the shell eats $, *, \ before grep sees them.
  • BRE vs ERE: + ? { } ( ) need backslashes in plain grep/sed, not in -E.
  • a* matches zero a's too, so "at least four a's" needs a.*a.*a.*a or \(.*a\)\{4,\}.
  • 忘了加引号：$、*、\ 在 grep 看到之前就被 shell 处理掉了。
  • BRE 与 ERE：普通 grep/sed 里 + ? { } ( ) 要加反斜杠，-E 里不用。
  • a* 也匹配 0 个 a，所以“至少 4 个 a”要写 a.*a.*a.*a 或 \(.*a\)\{4,\}。

#Grepping the dictionary在单词表中 grep

Q (capitalised); start with r/R; end in j; count of q any case; first five with 'cl'; 'kp' but not 'ckp'; last 15 two-letter words; three-letter words with no vowels; 7 letters, 3rd 'e', ending 'ded'; start with p/P with ≥4 a's.

含大写 Q；以 r/R 开头；以 j 结尾；忽略大小写含 q 的个数；含 'cl' 的前 5 个；含 'kp' 但不含 'ckp'；最后 15 个两字母词；不含元音的三字母词；7 个字母、第 3 个是 e、以 ded 结尾；以 p/P 开头且至少 4 个 a。

Show reference solution展开参考答案try it yourself first先自己做
grep 'Q' words
grep '^[rR]' words                # or: grep -i '^r'
grep 'j$' words
grep -ci 'q' words
grep 'cl' words | head -n 5
grep '[^c]kp' words
grep '^..$' words | tail -n 15
grep '^[^aeiou]\{3\}$' words      # course key also excludes y: [^aoeuiy]
grep '^..e.ded$' words
grep -i '^p\(.*a\)\{4,\}' words   # or: grep -i '^p.*a.*a.*a.*a'

#Sed exercisessed 练习

day→week on words ending 'ay'; words starting with s → 'sway'; duplicate 'day' after a space; 'Xday' → 'Xday or Xweek'; flip 'someday' → 'day (some)'; what does g do?

对以 ay 结尾的词把 day 改成 week；以 s 开头的词改成 'sway'；在含 day 的行后面再重复一个 day；'Xday' → 'Xday or Xweek'；把 'someday' 翻成 'day (some)'；g 的作用是什么？

Show reference solution展开参考答案try it yourself first先自己做
grep 'ay$' words | sed 's/day/week/'
grep 'ay$' words | sed 's/^s.*/sway/'
sed 's/.*day.*/& day/' words
sed 's/^\(.*\)day$/\1day or \1week/' words
sed 's/^\(.*\)\([dw]ay\)$/\2 (\1)/' words
echo banana | sed 's/a/e/'    # benana   (first match only)
echo banana | sed 's/a/e/g'   # benene   (every match on the line)

#More grep: -w, -o vs -c, spellings, postcodes更多 grep：-w、-o 与 -c、拼写、邮编

1. A file where grep PATTERN returns two lines but grep -w PATTERN one. 2. When do grep -o P f | wc -l and grep -c P f differ? 3. Match encyclopaedia/encyclopedia (and nothing else); color/colour. 4. UK postcode schema: two letters, one digit, optional space, digit, two letters. 5. Find a postcode the long official regex accepts but the simple schema rejects.

1. 构造一个文件，使 grep PATTERN 返回两行而 grep -w PATTERN 只返回一行。2. grep -o P f | wc -l 和 grep -c P f 什么时候结果不同？3. 只匹配 encyclopaedia/encyclopedia；color/colour。4. 英国邮编简化规则：两个字母、一个数字、可选空格、一个数字、两个字母。5. 找一个长版官方正则接受、但简化规则不接受的邮编。

Show reference solution展开参考答案try it yourself first先自己做
printf 'cat\ncatalogue\n' > f.txt
grep cat f.txt        # cat, catalogue
grep -w cat f.txt     # cat   (-w = whole word)

echo banana | grep -c a          # 1  (counts LINES)
echo banana | grep -o a | wc -l  # 3  (counts MATCHES)

grep -x 'encyclopa\?edia' words  # -x = whole line must match
grep -x 'colou\?r' words

grep '^[A-Z]\{2\}[0-9] \?[0-9][A-Z]\{2\}$' postcodes.txt   # e.g. BS8 1UB

5: e.g. M1 1AE (one letter), SW1A 1AA (letter after the digit), GIR 0AA, BFPO 123 — all valid in the full regex, rejected by the two-letters-one-digit schema.

第 5 题：如 M1 1AE（只有一个字母）、SW1A 1AA（数字后还有字母）、GIR 0AA、BFPO 123——完整正则都接受，简化规则都拒绝。
